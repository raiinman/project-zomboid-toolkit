# Desktop toolbelt

Mode: Operate. Native Windows Tk application.

Success is connecting the user and Codex to a loaded debug game without creating
a mod, choosing project folders or saving a scenario. The user's existing mod
stays in its own editor; the game's Mods menu controls activation.

## First view: Connection

Open with the retained distressed Dead Signal Interactive logo, a contained
130-pixel derelict-workshop image, a literal status message and Connect to game.
That action uses saved connection settings, installs the helper if needed and
checks the game. Keep the exact launcher label Launch Project Zomboid (test
profile). Explain enabling PZ Toolkit Bridge, loading a single-player world and
unpausing before Check connection. Existing running test games can be connected
without another launch. State debug/startup god mode and separate saves plainly.

Next-step instructions describe the actual result. Launching alone is not a
connection. Fresh readiness and actual god mode determine success.

## Game tools

The sidebar has only Connection and Game tools. Game tools opens on Built-in
editors, with debug, vehicle, attachment, animation and world-map controls,
god-mode on/off, logs and connection checks. A successful request is not proof
that an editor window is visible. Remind the user that an editor can pause the
game, requiring unpause before the next command.

Lua command (advanced) is a separate inner tab, with inline code, an explicit
trust checkbox and Run Lua command. It creates no scenario or per-command report
file. Editing code resets trust. Details (technical output) starts collapsed;
plain results remain visible. The app need not stay open for Codex to use MCP.
