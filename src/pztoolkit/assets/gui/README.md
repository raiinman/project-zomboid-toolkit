# Desktop identity assets

- `dead-signal-distressed.png`: generated surface treatment of the user's actual
  reverse Dead Signal Interactive logo from their Dead-Signal-Brand-Kit. The user
  approved distressing it. The symbol shape and wordmark remain recognizable.
  v0.3.0 preserves this PNG byte-for-byte in the navigation rail.
- `derelict-workshop.png`: original built-in image-generation artwork for the
  v0.4.0 bridge-first home page. Empty corroded industrial workshop, warm amber
  and rust-red lighting, no green or creature figures. Its exact prompt is in
  `derelict-workshop-prompt.txt` and PNG text metadata. The UI crops its display
  within a contained banner; controls remain on solid readable surfaces.
- `studio-icon.png`: the user's original DS transparent profile mark from that
  same kit, retained for the application window icon.
- `containment-header.png`: original generated environmental artwork, corrected
  to remove all creature figures per the user's instruction. Retained as source
  artwork; the v0.3.0 sidebar GUI does not display it.
- `fonts/`: privately loaded Oxanium SemiBold, bundled with its SIL OFL license
  and official source/derivation record.

Artwork was produced with the built-in image-generation tool. Prompts are in
`prompts.md`. Runtime display uses Tk image scaling, leaving source PNGs intact.
No movie/game character assets or installed Project Zomboid files are bundled.
The approved distressed logo bytes are unchanged. Its origin is recorded here
instead of rewriting its PNG metadata; the studio icon's origin is embedded.
